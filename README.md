# Laser Defender

## About the Game

**Laser Defender** is a top-down space shooter where players control a spaceship to shoot enemies and dodge attacks. The game features fast-paced combat, increasing difficulty, and power-ups for an exciting arcade experience.

## Features

- 🚀 Fast-paced space combat

- 🔥 Enemy waves to defeat

- 🎯 Simple shooting mechanics

- 🎵 Immersive sound effects

##  Installation

Requirements

- Unity

- Git

- PC/Mac with sufficient storage and RAM

### Clone the Repository
```bash
git clone https://github.com/matanyak/LaserDefender.git
cd LaserDefender
```

### Open in Unity

- Open Unity Hub

- Click **Open Project**

- Select the cloned folder

### How to Play

- **Move** - WASD or Arrow Keys

- **Shoot** - Space

- **Dodge** - Avoid enemy attacks

- **Survive** - Progress through waves and defeat bosses
